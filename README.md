# Java Method Overriding Programs

This repository contains Java programs demonstrating **Method Overriding** in Object-Oriented Programming (OOP).

These programs were created to practice and understand how a subclass can provide its own implementation of a method that is already defined in its parent class.

## 📚 Concepts Covered

* Method Overriding
* Inheritance
* Runtime Polymorphism
* Dynamic Method Dispatch
* Parent and Child Classes
* Method Implementation in Subclasses

## 🛠️ Technologies Used

* **Programming Language:** Java
* **IDE:** Eclipse IDE

## 🚀 How to Run

1. Clone or download this repository.
2. Open the Java source files in Eclipse IDE or another Java IDE.
3. Open the desired Java class.
4. Run the program as a Java Application.

## 🎯 Purpose

This repository was created for Java programming practice and to strengthen my understanding of **Method Overriding, Inheritance, and Runtime Polymorphism**.
